Online shops

An AI agent for online shops

Questions about orders, delivery and exchanges arrive all day. The agent drafts a reply from what the customer has already written. You approve it before it goes out.

Order status

The agent drafts a reply about where the order stands, using the enquiry and the order history.

  • Order questions in one place
  • A draft reply
  • You approve it before it is sent

Delivery

The agent suggests a reply when a customer asks about delivery, and leaves you to correct anything that is off.

  • A draft about delivery
  • You add what is missing
  • It is sent only after approval

Exchanges and returns

The agent drafts an explanation of how an exchange or a return is handled, in the shop's own words.

  • A draft reply about an exchange
  • The return marked for follow-up
  • You decide what is sent

Example: a question about where an order has got to receives a draft based on the enquiry itself. The reply is sent only after someone in the shop has approved it.

The agent is set up in your own accounts. Ready in a few hours. The agent subscription is extra, and you pay the vendor directly.
